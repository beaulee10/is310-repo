# Decade's Top Hits Curation Tool

This is a CLI (Command Line Interface) application designed to curate a list of the top musical hits from the past decade.

## Setup Instructions
1. Clone this repository.
2. Create and activate a virtual environment:
   - `python3 -m venv music-env`
   - `source music-env/bin/activate`
3. Install the required library:
   - `pip install rich`

## How to Use
Run the script using:
\`python3 cli_data_entry.py\`

The script will display current top hits and allow you to manually enter new songs, confirm the data, and save it to a JSON file.
